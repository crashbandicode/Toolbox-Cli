# CURSOR.md

The canonical agent operating bar for this repo lives in **[`AGENTS.md`](./AGENTS.md)** —
the METHOD, QUALITY BAR, PRE-COMMIT CHECKLIST, OVERNIGHT EXECUTION MODEL,
CONSTRAINTS, WHEN TO HAND OFF, and HANDOFF PROTOCOL.

`AGENTS.md` is the **single source of truth**. This file is intentionally a pointer
and not a copy: duplicating the bar would let the two files drift, which is exactly
the failure mode the bar exists to prevent. Read and follow `AGENTS.md`.

Per-session state (STATUS, CHECKPOINT PLAN, progress ledger) lives in
`AGENTSSUMMARY.md` and the current session handoff — not here.
